本项目采用 MIT License，可用于内部部署、顾问交付和商业发行。第三方订阅内容仍受其各自条款约束，发行方应自行确认使用权。

## 最小白标步骤

1. 修改 `.knowledgeflow/config.json` 中的项目名、主题目录、关键词和来源白名单。
2. 替换 `00-导航/00-首页.md` 的品牌与使用说明。
3. 修改插件 `manifest.json` 的 ID 与名称，避免与上游插件冲突。
4. 更新 `USER_AGENT`，提供可联系的产品主页。
5. 用至少一个真实来源运行 7 天，记录误入率、重复率和来源失败率。
6. 发布前清空 `.knowledgeflow/data/`，并执行密钥与隐私扫描。

## 建议的产品验收指标

| 指标 | 建议门槛 |
|---|---:|
| 重复入库率 | 0% |
| 自动文章来源覆盖率 | 100% |
| 自动文章元数据完整率 | 100% |
| 来源单点故障影响 | 不阻断其他来源 |
| 人工抽检误入率 | 连续 7 天低于 10% |
| 删除后回流率 | 0% |

高风险行业必须增加专业人员复核，不应把自动评分包装为事实认证。
