# 2026-08 生产更新汇总

这份文档整理了本地生产知识库在 2026 年 7 月中旬至 8 月 18 日期间验证过、并已抽象到开源项目中的改进。它不包含个人笔记、运行账本或云盘路径。

## 已落地能力

### 1. 固定来源与增量采集

生产实例已从最初的演示来源扩展到覆盖中国监管与统计、国际贸易、金融稳定、能源、矿业、医药、网络安全和 AI 的固定来源体系。来源仍采用白名单、权威等级、主题关键词和最大抓取量控制；来源异常只隔离单个来源，不阻断其他来源。

### 2. 空摘要详情页补抓

部分政府站点和 HTML 详情页只提供标题与链接，RSS 摘要为空会造成误过滤。现在可以对标记为 `html` / `html_detail` 或显式开启 `detail_fallback` 的来源抓取原文详情页，从 `article`、`main` 或内容容器提取可读文本，自动排除导航、脚本、页眉和页脚。详情页失败是非致命事件，仍保留来源候选；HTML 列表页的条目发现仍由站点专用适配器负责。

### 3. 可审计的拒绝重试

`--retry-rejected` 只重试因摘要不足而被过滤的候选。系统先把详情页补抓结果写回候选账本，再记录 `requeued`，最后产生新的终态决策。这样既能释放原本被误过滤的高质量来源，也不会绕过人工删除防回流规则。

### 4. 无模型密钥时的安全降级

抓取、评分、入库和知识综合不依赖模型密钥。没有密钥时，系统只生成隔离提案和带有“自动证据草稿 / 待核验”标记的草稿页，并将其排除在主要 RAG 检索之外；不会把来源摘要冒充成已经验证的知识结论。

### 5. 队列、路由与健康度

知识流入现在明确区分：来源卡、自动证据草稿、可转化专题、已转化专题和长期监测主题。质量报告会同时检查来源 ID、候选 URL、决策状态、草稿路径、结构化来源和知识页质量门槛。

### 6. macOS 后台运行稳定性

生产环境使用 LaunchAgent 每日调度，并通过并发锁避免重复运行。实测需要把标准输出和错误日志放到本机 `~/Library/Logs`，不要放在 CloudDrive/iCloud 等文件提供商目录，否则 macOS 可能在启动前拒绝打开重定向文件并返回 `EX_CONFIG` / `Operation not permitted`。

## 尚未默认纳入核心的能力

- HTML 列表页的站点专用解析器仍应作为来源适配器实现，不应把每个站点的 DOM 规则硬编码到通用引擎；
- X 等需要登录态的站点不作为默认来源，需通过独立、可撤销的浏览器适配器接入；
- 向量索引和 LLM 综合应继续位于证据账本之后，并保留输入、提示、输出和版本记录。
