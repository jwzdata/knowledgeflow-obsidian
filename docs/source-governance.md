# 来源治理

固定来源不是“永远可信”，而是“责任主体明确、可持续观察、可审计”。建议每季度复核一次来源白名单。

## 分级建议

- **A 级**：政府、监管机构、标准组织、原始统计发布者；默认权威性 100。
- **B 级**：同行评审入口、大学、信誉良好的研究机构；默认权威性 82。
- **C 级**：企业官方博客与专业媒体；默认权威性 65，建议提高入库门槛。

## 新增来源检查表

- 发布主体能否明确追责；
- RSS/Atom 地址是否公开且长期稳定；
- 是否给出发布日期、原文链接和有信息量的摘要；
- 是否大量发布营销、转载或无正文链接内容；
- 使用条款是否允许订阅和个人归档；
- 是否与主题目录存在明确映射；
- 最近 30 天的误入率是否可接受。

## 维护方式

来源异常不会中止其他来源。查看 `20-知识流入/00-流水线收件箱.md` 的异常数，必要时将来源的 `active` 改为 `false`。不要通过关闭 TLS 校验来“修复”来源。

对于 arXiv、媒体聚合等覆盖面很宽的订阅，设置 `"require_keyword": true`。这会在自动入库门禁中强制至少命中一个主题关键词，避免仅因来源等级较高而误入边缘内容。
